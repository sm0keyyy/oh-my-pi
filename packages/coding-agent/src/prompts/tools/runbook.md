Show a runbook only for commands you cannot run and a human must run. Nothing executes until the operator picks Run or Run all. Use 1 to 20 steps. Each command is at most 4 KiB. Name the host (mac or unraid), and set interactive for input such as sudo or a password. The operator types into a real floating Rex terminal. Only captured output returns; never request secrets in the command. Results arrive as background-job messages. Run all stops on the first failure.
In a subagent pane, the operator can use /run <n> or /run all for that agent's latest runbook when links cannot be picked. Interactive Unraid steps wait in the Unraid session "omp: runbook". Commands and cwd are shown before Run. A non-echoed password is not captured; echoed input remains in program output.
